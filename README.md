# AI-Powered Workplace Productivity Assistant
By Karabo Keohitlhetse | ASA 23 JHB | Week 23

## Overview
An AI-powered tool that helps professionals save time on daily workplace tasks: email writing, meeting summarization, and task planning.

## Features
1. Email Generation - generates professional emails
2. Meeting Summarization - summarizes long notes
3. Task Planning - creates daily plans

## Tools Used
- ChatGPT / Meta AI for prompting
- HTML, CSS, JavaScript
- GitHub Pages
